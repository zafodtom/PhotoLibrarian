# PhotoLibrarian 1.2.4 — Cinematic UI 2.0

Stable Windows x64 release following v1.2.3.

## Unified workspace design

- Complete the industrial dark/cyan styling of the gallery, LIBRARY and TAGS navigation, asset metadata, Settings, image editor, people review, album-folder management and the startup sequence.
- Harmonize headers, command rails, button borders, field typography, status panels and overlay controls without reducing the photo viewing workspace.
- Distinguish tag filter include (+) and exclude (−) controls with separate visual accents.
- Keep the original virtualized thumbnail/gallery implementation, album tagging logic, fullscreen navigation and photo editing behavior.

## Dialogs and operational feedback

- Correct WinUI dialog placement: use its native popup presenter for centering, with sizing applied to the content rather than fixed Width/MaxWidth on ContentDialog itself.
- Use cinematic WARNING panels for important destructive actions, ERROR for failed operations, FATAL ERROR for critical album failures and PROCESS COMPLETE after successful long-running album maintenance.
- Preserve compact dialogs for routine renaming and tag input.
- Standardize primary, destructive and neutral secondary buttons (Cancel, Close, Abort), including their disabled visual states.
- Remove both development-only dialog preview tools from Settings: the original PREVIEW ALL DIALOGS sequence and the Cinematic UI SHOWCASE. Real dialogs remain functional.

## Testing and safety

- Windows CI builds the application and runs automated tests; dialog routing, XAML integrity, button styles and absence of preview controls are covered by regression tests.
- Album maintenance still requires the existing explicit confirmation; no new destructive behavior is introduced by the visual changes.
- Back up important albums before destructive operations. Large photo collections and metadata cache operations retain their established data handling.
