# PhotoLibrarian 1.2.5 — photo tools and gallery search (development)

Prerelease following stable 1.2.4. Not yet approved for stable master.

## Crop: save as
- The crop toolbar now offers SAVE AS beside the original destructive APPLY and CANCEL controls.
- Windows App SDK Save dialog opens in the current photo's folder by default and still lets the user choose path, filename and output format (JPG, PNG, TIFF, BMP).
- The exported image is written atomically to a temporary sibling file before replacement of the chosen target. Original image and XMP remain unchanged.
- An exported crop is a new independent picture and is not automatically assigned the tags or face metadata of its source.

## Rotate and save
- Two buttons in both normal and fullscreen viewer rails use distinct directional rotation icons to rotate the currently open photo 90° left or right and save it.
- The original is backed up using the album's existing backup service before the pixel rotation.
- If updating face XMP/sidecar metadata fails after rotation, the metadata transaction is rolled back and the previous photo is restored from backup.
- The viewer, dimensions and thumbnail cache are refreshed after the operation.
- Only formats supported by the existing editor are enabled (JPG, PNG, TIFF, BMP); video is excluded.
- Face-detection and embedded/sidecar geometry on rotated images require manual validation before promotion to stable.

## Gallery workflow
- Remove the GROUP selector from the toolbar and use the existing flat, sorted virtualized gallery.
- Keep SORT with File Name, Date Taken, Date Modified and File Size.
- Replace the advanced tag/media/extension Filter flyout with simple case-insensitive filename search (SEARCH / clear / Enter).
- Existing tag filtering remains available from the hierarchical TAGS navigation at left.
- SORT, SEARCH, CLEAR and thumbnail zoom controls now share consistent 34px toolbar height, button styling and icon proportions.

## Verification
- Automated WinUI application build, existing tests and new filename search tests.
- Manual tests needed for save-dialog path selection, EXIF orientation in quarter-turn rotation, backups, metadata consistency and gallery search behavior.
