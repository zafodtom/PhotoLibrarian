# PhotoLibrarian 1.1.6 — Trimenor

Stable Windows x64 maintenance release.

## New: Convert album images to JPEG

A new **ALBUM // JPEG CONVERSION** section in Settings provides:

- A preview scan of the current album and its subfolders showing eligible conversions, JPEGs with sidecar XMP, and filename conflicts.
- Batch conversion of supported image formats to JPEG, with quality set to 95% for images requiring encoding.
- Embedding of standard XMP sidecar contents directly in the resulting JPEG APP1 metadata without discarding unrecognized XMP properties.
- Existing JPEGs with sidecar XMP are modified without recompressing the image pixels.
- Destination collision protection, per-file verification, progress display and cancellation.
- Original images and XMP sidecars retained under `.album/jpeg-conversion-backups/`, grouped by run.
- Remapping of existing album database image paths so photo identities and associated information remain linked.
- Nested PhotoLibrarian albums, unsupported images and videos are excluded from conversion.

**Important:** JPEG conversion is lossy for non-JPEG originals and may not preserve all original embedded metadata outside the XMP sidecar. Multi-frame/animated and RAW formats are not automatically converted. Large XMP packets that cannot fit in standard JPEG APP1 are rejected instead of truncated. Retain the backed-up originals until you inspect representative results.

## New: Reset all album tags and flags

A separate **ALBUM // RESET TAGS** section in Settings provides:

- A photo count and explicit confirmation before the album-wide operation.
- Removal of image keywords, PhotoLibrarian flags and catalog tag names from the active album.
- Updates to both supported in-file metadata / XMP sidecars and the PhotoLibrarian image database.
- Preservation of photo files, ratings, captions, dates and face associations.
- Backups under `.album/metadata-reset-backups/` and an error report for any files that could not be safely updated.
- Progress feedback and cancellation; completed items remain processed.
- Automatic tagging switched off so cleared tags do not immediately return.
- Fail-safe behavior for unsupported formats: they are reported rather than silently losing metadata.

**Important:** Reset is not an automatic undoable operation. Back up the album separately and test on a copy before performing either bulk operation on irreplaceable photographs.

## Fixes and quality

- Corrected a Windows build error caused by ambiguous `FileAttributes` references.
- Corrected missing namespace imports and isolated the prior viewer-delete regression test from the new reset code.
- Added automated checks for JPEG/XMP packet embedding, source backup preservation, JPEG conversion, album preview boundaries and targeted metadata removal.
- Latest branch CI and Windows packaging checks passed before merging.

## Updating

From PhotoLibrarian 1.1.5, select **Settings → CHECK FOR UPDATES** after this release is published, or install the Windows x64 setup package over your existing installation.

The installer is unsigned, so Windows may show SmartScreen/UAC notices.
