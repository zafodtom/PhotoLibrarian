# PhotoLibrarian 1.1.5 — Trimenor

Stable Windows x64 update.

## Changes

### Tag navigation and filtering
- Added an **ALL (AND) / ANY (OR)** selector in the left tag navigation panel. ALL narrows results to photos matching every included tag; ANY matches at least one.
- Added explicit **+ Include** and **− Exclude** controls for each tag. Excluded tags always remove matching photos.
- Hierarchical tag matching includes descendants of the selected tag path.
- Added **Search tags**, a summary of active tag conditions, a matched-photo count, and **CLEAR** for tag conditions.
- Preserved the full hierarchical tag tree while filtering. Tags with zero matches remain visible with reduced emphasis.
- Tag counts reflect currently matching gallery photos and are updated using indexed metadata rather than reading XMP sidecars per result.
- Tag filtering respects the selected album folder scope.

### Viewer deletion and metadata
- Fixed metadata and tag assignments displaying from the previous grid selection after deleting a photo in the viewer.
- Kept metadata associated with the image currently shown in the viewer.
- Refreshed the tag navigation tree using the selected folder scope rather than briefly loading unscoped album tags.

### Testing
- Added regression tests for AND/OR matching, inclusion/exclusion, hierarchical paths, untagged images, facet counts and viewer-to-metadata selection handling.

## Installation and updates
Install the Windows x64 setup over an existing version, or use **Settings → CHECK FOR UPDATES** in PhotoLibrarian 1.1.4. Existing albums and data are preserved.

The installer is not code-signed, so Windows SmartScreen/UAC may require confirmation.
