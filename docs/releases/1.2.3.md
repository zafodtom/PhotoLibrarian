# PhotoLibrarian 1.2.3 — Photo-first Cinematic UI baseline

Stable Windows x64 release following 1.2.2. This release incorporates the previously tested Cinematic UI development line and its photo-first widescreen workspace improvements.

## Layout and navigation

- Make more room for photos with a compact global header, smaller status bar and reduced viewport margins.
- Remove the redundant BROWSE heading, retaining library navigation and moving Open Album / Refresh actions into LIBRARY.
- Remove the redundant All Photos heading in ungrouped views while retaining actual group labels; show the number of visible photos in the existing gallery toolbar.
- Reduce unnecessary padding around the LIBRARY and TAGS trees while preserving their hierarchy and filtering behavior.
- Move viewer zoom, actual-size (100%), crop, fullscreen, delete and back-to-gallery commands to the left rail.
- Add a compact side overlay in fullscreen without reserving image width.
- Move filename and photo position to the global header. The true zoom indicator remains at the lower-right corner of the photo.
- Keep the crop aspect/Apply/Cancel ribbon available only during cropping.

## Cinematic dialogs

- Add Settings → SYSTEM // UI SHOWCASE with six safe previews: FATAL ERROR, ERROR, WARNING, PROCESS COMPLETE, INFORMATION and PROCESSING.
- Introduce film-inspired warning panels and apply them to selected album maintenance and deletion confirmations; original operations and cancellation gates remain unchanged.
- The preview sequence is demonstration-only and does not write files or modify metadata.

## Validation and cautions

- The Windows CI pipeline and automated tests passed for the merged development baseline. The stable installer workflow rebuilds and retests before publication.
- Manual verification of gallery, tags, viewer and fullscreen controls was completed during the development iteration.
- The previously documented untagged-filter tag-picker scroll issue is not claimed to be fixed by this release.
- Back up important albums, databases and metadata before destructive maintenance.
