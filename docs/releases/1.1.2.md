# PhotoLibrarian 1.1.2 — Trimenor

Stable Windows x64 release. This update brings the recent photo-grid, thumbnail-cache and application-updater improvements together.

## Changes

- **Viewer return selection:** when leaving the photo viewer or full-screen view, the grid selects the **last displayed photo**, rather than the photo originally opened. Its thumbnail scrolls into view automatically.
- **Default ordering:** photos are initially sorted by **file name, ascending (A–Z)**. You can still change sorting manually.
- **Thumbnail maintenance:** cached 180/256 px thumbnails are removed when their photo or containing folder is successfully moved to the Windows Recycle Bin. A deferred, at-most-daily background cleanup removes orphaned album-cache entries left by files deleted elsewhere.
- **In-app updater:** new photo-library sci-fi-themed confirmation overlays and a separate branded update helper. After explicit confirmation, the helper verifies the SHA-256, waits for the app to close, installs without the normal Inno Setup wizard and relaunches PhotoLibrarian, restoring the previously opened album. Windows UAC/SmartScreen may still be shown.
- **Settings layout:** the configuration footer no longer extends underneath the main SYS status bar.
- Includes existing improvements to thumbnail performance, selections, hierarchical tag filtering and diagnostics.

## Installation and updating

Install over an existing PhotoLibrarian installation; the installer application ID, album data and photo locations remain unchanged.

**From PhotoLibrarian 1.1.1:** open **Settings → CHECK FOR UPDATES** and accept version **1.1.2**. The currently installed 1.1.1 updater still uses the standard Inno Setup wizard when performing this upgrade. **The redesigned silent update and auto-restart workflow is included in 1.1.2 and will apply to future releases.** This is expected.

The updater downloads the official release installer and validates the size and SHA-256 digest. You can alternatively run the x64 installer directly.

**Windows security:** the installer is not Authenticode-signed; SmartScreen and UAC dialogs may appear. Administrator privileges may be required.
