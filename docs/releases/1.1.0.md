# PhotoLibrarian 1.1.0 — Trimenor

New Windows installer/release pipeline and manual in-app updates.

- Adds **Settings → CHECK FOR UPDATES** for manually checking the newest public stable PhotoLibrarian GitHub Release.
- Downloads only the matching x64 installer from the official repository and verifies its expected size and SHA-256 digest before offering installation. Requires user confirmation; no automatic update checks.
- Adds Windows GitHub Actions build, tests, installer upload and a separately approved stable-release publication step.
- Integrates the approved Trimenor brand in About, Windows product metadata and Inno Setup publisher fields. Keeps the PhotoLibrarian name, icon, album format, installer AppId and data paths.
- Retains previous thumbnail, selection, tag and performance work from the development branch.

**Install or upgrade:** Run the x64 installer; the existing PhotoLibrarian application identity is preserved. Test installed-app upgrades on Windows before publishing. No code-signing certificate is included, so SmartScreen may still warn about an unknown publisher.

**Updating from the app:** Available once this version has been installed and a newer, *published stable* GitHub Release exists. Actions artifacts are for testing and are not update releases.
