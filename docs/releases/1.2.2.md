# PhotoLibrarian 1.2.2 — Trimenor

Stable Windows x64 release following **1.2.1**. This release promotes the development line tested with a large real-world tagged album.

## Tagging and filtering

- Search available tags regardless of Czech diacritics or letter case, including hierarchical tag paths; stored tag names remain unchanged.
- The complete tag list supports consecutive assignments without intentionally closing the picker. Selecting a tag from **typed search** closes the results and clears the search term.
- Keep five recently used tag shortcuts per album and exclude already-assigned tags from the quick selection. Display compact leaf names without losing the full tag paths.
- Tag edits made with the individual photo viewer open are saved immediately while tag-dependent gallery filtering is deferred until returning to the gallery. Photos that no longer match an active filter are then removed from the filtered gallery.
- Retain the hierarchical tag filter UI, including included/excluded tags.

## Interface and maintenance

- Refine the metadata panel and settings layout. The FILE / EXIF information area starts collapsed.
- Settings navigation positions the selected section header at the top of the viewport.
- Add **Settings → ABOUT → PREVIEW ALL DIALOGS** for safe, nonfunctional visual inspections of representative dialog designs; preview actions do not edit files, tags, or settings.
- Keep the existing album maintenance, thumbnail, and update mechanisms.

## Known issue

- With the **Untagged / bez tagů** filter active, the right-hand complete tag list can still jump to the beginning after assigning a tag. This visual issue is **not fixed** in 1.2.2. Unsuccessful experimental workarounds were removed instead of being carried into this release.
- The dialog preview is a representative design inspection, not an interactive reproduction of every production dialog.

## Validation and installation

- Windows CI and automated tests passed on the final development line. The final stable release workflow rebuilds and retests the Windows x64 installer before publication.
- The tag-list scrolling issue requires a manual WinUI interaction check; automated tests do not prove its visual behavior.
- Back up important albums, including database and metadata, before bulk destructive maintenance.
- After publication, install through **Settings → CHECK FOR UPDATES** or the official Windows x64 installer. Existing Inno Setup update behavior retains previously selected installer options.
