# PhotoLibrarian 1.1.7 — Trimenor

Stable Windows x64 maintenance and workflow release.

## Fixed: album backups must never appear as photos

- Exclude `.album` and all its internal backup and temporary directories from every photo-indexing entry point, including file-system watcher updates.
- Remove only obsolete SQLite index entries for previously misindexed backups during reindex; never delete any backup files on disk.

## Fixed: incomplete album tag/flag reset

- Clean database-only tags without rewriting unmodified image files.
- Support RAW and other images whose tags exist only in the database or XMP sidecars.
- Verify metadata changes, use per-image SQLite transactions, retry selected transient sharing errors, and record individual errors in `.album/metadata-reset-backups/<run>/reset-errors.txt`.
- Discover eligible photos that are missing from the index, refresh tag navigation, and preserve ratings, captions, dates and other unrelated metadata.
- Backups under `.album` are excluded from album reset and indexing.

## Reliability and performance

- Fix drag-and-drop initialization in grouped and flat galleries, with guarded failures and completed drag deferrals.
- Move time-consuming file copy/move work off the UI thread to reduce freezes; keep unsuccessful cut items available for retry.
- Improve JPEG conversion efficiency while retaining its verification, XMP and rollback safeguards.
- Style album-maintenance dialogs consistently with PhotoLibrarian's dark futuristic interface.

## Tag-first interface

- Correct filename A–Z default sorting.
- Remove retired refinement controls and unused Store/MSIX distribution paths without deleting existing user metadata.
- Preserve the advanced image editor and optional automatic-tagging infrastructure.
- Record the ModelBench separation plan; standalone migration is not complete.

## Development update channel

- Optional development-update setting, disabled by default.
- Allow prereleases built manually from non-master branches, with SemVer ordering and protection against unintended downgrades.
- Stable releases remain manual and restricted to master.

## Validation and updates

All six component pull requests (#14–#19) passed their Windows CI and Windows installer build checks individually before merge. A complete integration build and interactive Windows smoke test on a **copy** of a representative album are still recommended; these notes do not assert they have already passed.

Use **Settings → CHECK FOR UPDATES** after v1.1.7 is published, or install the Windows x64 Inno Setup package over the existing version. The installer is unsigned, so Windows may show SmartScreen/UAC notices.
