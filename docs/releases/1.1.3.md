# PhotoLibrarian 1.1.3 — Trimenor

Stable Windows x64 release.

## Changes

- **Recent tags:** The Asset Metadata panel now offers a **RECENT TAGS** quick-selection list immediately below **Add or choose tag**.
- **One-click assignment:** Click any recent tag to assign it to the currently selected photo or photos, using the existing tag-writing workflow.
- **Five latest tags:** The list shows up to five unique, recently assigned tags, ordered from newest to oldest. Reusing a tag moves it to the top.
- **Persistent history:** Recent tag shortcuts are restored across restarts, stored locally in `%LOCALAPPDATA%\PhotoLibrarian\recent-tags.json`.
- The recent-tags section remains hidden until a tag has been assigned.

## Installation and updating

Install over an existing PhotoLibrarian installation or use **Settings → CHECK FOR UPDATES** in an installed previous version. PhotoLibrarian retains existing albums and user data.

The installer is not Authenticode-signed. Windows SmartScreen or UAC may require confirmation.
