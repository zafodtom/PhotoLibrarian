# PhotoLibrarian 1.1.1 — Trimenor

Maintenance release prepared to validate in-app updating from PhotoLibrarian 1.1.0.

- Left-click a tag in the left navigation to include it (+); right-click to exclude it (−). Clicking the same mode again clears it.
- Exclusion works with individual tags, hierarchical tag paths, and when no inclusive tag is selected.
- Keeps the tag-removal cross before each tag in Asset Metadata.
- Includes the thumbnail, metadata-selection and performance fixes from 1.1.0.
- Provides the existing **Settings → CHECK FOR UPDATES** feature for subsequent releases.

**Updating from PhotoLibrarian 1.1.0:** Open Settings → CHECK FOR UPDATES, accept the 1.1.1 download and installation. The update is downloaded from this public GitHub Release and validated against its GitHub-provided SHA-256 digest before installation. You may also download the x64 installer directly.

**Windows trust:** The installer is not Authenticode-signed, so Windows SmartScreen may present an unknown-publisher warning. Confirm the release source before installing.
