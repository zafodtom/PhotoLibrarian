# PhotoLibrarian 1.1.4 — Trimenor

Stable Windows x64 update focusing on reliable tag filtering and more useful tag shortcuts.

## Fixes and improvements

- **Folder + excluded tags:** Fixed excluded photos incorrectly reappearing at the end of the selected folder's gallery as unindexed, uneditable duplicates.
- **Correct indexing comparison:** Folder scanning now distinguishes database-indexed photos from files genuinely missing from the library, even when other gallery refinements hide the indexed photos.
- **Tag-filtered galleries:** Avoid disk-only temporary entries when tag inclusion or exclusion is active, as those entries do not have the metadata needed for reliable filtering.
- **Tag suggestions:** When the tag picker is open, it appears above/in place of the recent-tag shortcuts; recent shortcuts return when the picker closes.
- **Recent tags:** Tags already assigned to every selected photo no longer appear as quick selections. For multi-selection, a tag remains available if at least one photo is missing it.
- **Album-specific recent tags:** Each album has its own persistent five-tag history. Switching albums no longer carries quick selections between unrelated albums. Existing global history is not imported into album histories.
- Regression tests for folder-scan filtering.

## Updating

In PhotoLibrarian 1.1.3 choose **Settings → CHECK FOR UPDATES** and install 1.1.4. You can also install over the existing application using the Windows x64 setup file. Existing album and photo data are preserved.

The unsigned installer may prompt Windows SmartScreen or UAC.
