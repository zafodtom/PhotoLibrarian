# PhotoLibrarian 1.2.0 — Trimenor

Stable Windows x64 release based on the verified `v1.2.0-dev.4` development line.

## Platform and stability

- Upgrade the application and test projects from .NET 8 to .NET 10 LTS. The installer remains self-contained.
- Prevent internal `.album` working folders, backups, and nested albums from appearing in grid scans or thumbnail lists. Legacy indexed backup records are hidden from the photo grid.
- Avoid executing the optional native libheif thumbnail fallback inside the main process, mitigating a potential native crash (`0xC0000005`). HEIF thumbnails use the Windows thumbnail provider.

## Album conversion to JPEG

- Support conversion of HEIC/HEIF where the available Windows image decoder supports the source file; report actionable errors when decoding fails.
- Never overwrite an existing JPG when converting another file with the same basename. Automatically select a numbered suffix (`_001`, `_002`, etc.), preserving existing images.
- Improve XMP validation on .NET 10 using the built-in XML reader, and retain lossless metadata merging for already-JPEG images with XMP sidecars.
- Preserve per-file rollback and original-backup safeguards. Report cases where a verified conversion succeeds but cleanup of temporary originals is denied.

## Album tag reset

- Retry transient access and file-sharing failures at individual JPEG read, replacement and Windows keyword-update boundaries.
- Surface Windows keyword-reading errors during destructive reset instead of treating a failed read as an empty tag set.
- Improve stage-specific diagnostics while retaining rollback copies for failed operations and preserving unrelated metadata.

## Windows Explorer integration

- Optional installer task, enabled by default: **Create PhotoLibrarian album here** when right-clicking a folder or an empty area inside a folder.
- Reuse existing `--album` functionality. Already-initialized albums are opened rather than duplicated.
- Preserve the task preference during silent in-app installer updates. Remove Explorer registry entries when disabling the integration during an upgrade or uninstalling the application.
- On Windows 11 the item may appear under **Show more options**.

## Build and validation

- CI compiles and tests each pull request. Installer builds and stable/development publishing run only via manual GitHub Actions dispatch.
- The development `v1.2.0-dev.4` installer and CI completed successfully. HEIC conversion and album-wide tag reset were verified by the user on a small local sample.
- Network-backed large albums can be slower; comprehensive regression on large NAS albums has not yet been confirmed. Back up important photos before destructive album maintenance.

Use **Settings → CHECK FOR UPDATES** after the stable release is published, or install the official Windows x64 Inno Setup package. Unsigned installers may trigger Windows SmartScreen prompts.
