# PhotoLibrarian 1.2.2 — Development updates (Trimenor)

Development prerelease for Windows x64. The release workflow assigns a sequential `v1.2.2-dev.N` tag.

## Changes since 1.2.2-dev.5

- Fixed the right-hand complete tag picker jumping to the start when assigning tags to photos with the **Untagged** filter active.
- The open complete tag list now retains its existing WinUI item containers and scroll position across asynchronous metadata writes instead of rebinding the whole ListView.
- Pin/unpin icons and status labels update in place while the list remains open.
- Searching and selecting a tag still clears the search field and closes the results; Escape, focus-loss and accent-insensitive search remain unchanged.
- Added regression checks to protect against reintroducing complete-list ItemSource rebinding.

## Earlier DEV changes (through 1.2.2-dev.5)

- Recent tag shortcuts show just the leaf name; their full hierarchical tag path is preserved for assigning tags.
- Simplified recent tag shortcuts by removing unnecessary tooltip/hint and visual separator.
- FILE / EXIF details are now collapsible and initially closed.
- Settings navigation scrolls the selected section to the top, including ABOUT.
- Improved layout of the metadata details panel and settings navigation.
- Search in the right-hand tag picker now ignores accents and letter case, including full hierarchical paths; stored tag names are unchanged.
- The first iteration of the tag picker supported continuous selection; the behavior now distinguishes complete-list browsing from typed search results.
- Esc and clicking outside the picker continue to close the list.

## Validation

- The tag-picker scroll fix was merged to `develop/1.2.2` via PR #39.
- Windows CI #189 successfully built the application and ran the automated tests after this fix.
- The release workflow also compiles and runs tests before creating an installer and publishing a prerelease.

## Notes and limitations

- **Development build:** behavior may differ from the latest stable version.
- Before testing destructive operations such as bulk conversion or metadata reset, back up the affected album.
- Development updates are opt-in in **Settings → SYSTEM // UPDATE CONTROL → INCLUDE DEVELOPMENT UPDATES**.
- This prerelease does not change the stable release channel and does not modify `master`.
