# PhotoLibrarian 1.2.2 — Development updates (Trimenor)

Development prerelease for Windows x64. The release workflow assigns sequential `v1.2.2-dev.N` tags.

## Next development changes (after 1.2.2-dev.7)

- Removed the experimental tag-picker ListView rebind/scroll workarounds and the additional gallery-refresh suppression tied to the open tag picker. They did not resolve the reported scroll jump when assigning a tag while the **Untagged** filter was active.
- Removed regression tests that incorrectly treated the unsuccessful workarounds as verified behavior.
- Kept the original browse-vs-search picker behavior, accent-insensitive search, and deferred gallery refresh while the image viewer is open.
- Kept **Settings → ABOUT → PREVIEW ALL DIALOGS**, a safe visual-only showcase of dialog styles; added independent safety checks.

**Known issue:** With an active Untagged filter, the tag list may still jump to the top after assigning a tag. This remains unresolved; no further fix is claimed in this update.

## Previous development changes

- Recent tag shortcuts show leaf names while preserving full hierarchical paths.
- FILE / EXIF details start collapsed.
- Settings section navigation aligns the selected section to the top.
- Typed tag search ignores diacritics and case; selecting a search result closes the list and clears the search field.
- Complete-list browsing remains available for successive tag assignment.
- Viewer tag edits defer gallery filter refresh until the viewer is closed.

## Validation

- Automated build/test validation is performed by Windows CI before merge.
- Full interactive WinUI behavior, including the known tag-list scroll issue, requires user testing.

## Notes and limitations

- **Development build:** behavior may differ from stable.
- Back up albums before destructive bulk conversion or metadata reset testing.
- Development updates are opt-in through **Settings → SYSTEM // UPDATE CONTROL → INCLUDE DEVELOPMENT UPDATES**.
- The prerelease channel does not modify the stable `master` branch.
