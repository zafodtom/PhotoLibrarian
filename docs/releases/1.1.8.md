# PhotoLibrarian 1.1.8 — Trimenor

Stable Windows x64 release. Integrates the improvements tested in development prereleases `v1.1.8-dev.1` and `v1.1.8-dev.2`.

## Album-wide tag reset and metadata

- Improve reset diagnostics with the exact processing step, exception type and HRESULT in `reset-errors.txt`.
- Handle non-XML JPEG APP1 payloads without forcing them through the XMP parser. Avoid unnecessary Windows Shell keyword writes when there are no remaining Shell keywords.
- For standard embedded JPEG XMP, remove targeted keywords and PhotoLibrarian flags while preserving encoded pixels and unrelated metadata. Other embedded formats are still checked for leftover keywords; unsupported or read-only metadata may be reported as failures rather than incorrectly marked as cleaned.
- Preserve the tag catalog if any photos fail; keep unrelated ratings, captions and capture dates intact.

## Optional retention of backups

- Add separate **KEEP BACKUPS** checkboxes to the album tag-reset and JPEG-conversion panels. Both are enabled by default.
- If disabled, operations still stage temporary per-photo rollback copies for failures, but successful operations do **not** keep original image/XMP backup copies. This mode is intentionally irreversible.
- Record conversion failures in `conversion-errors.txt` and retain reset error diagnostics. Internal `.album` directories remain excluded from indexing.

## JPEG conversion and HEIC/HEIF

- Improve HEIC/HEIF diagnostics when the required Windows decoder is absent; on systems where Windows supports HEIF, select the primary image frame, including images containing auxiliary frames.
- Retry HEIC/HEIF pixel decoding without color management if a codec rejects color-profile processing.
- Preserve JPEG conversion validation, destination conflict protection, thumbnail decode checks and database path updates. HEIC support depends on codecs available on the target Windows computer and is not guaranteed for every file.

## Validation and installation

- Windows CI and Windows build/installer checks passed for the integrated development changes before the stable release preparation.
- Real-world bulk metadata reset and HEIC conversion have **not** been verified to work for all user files. Test first on a **copy** of an album and retain backups until satisfied.
- This remains a .NET 8 release. Migration to .NET 10 LTS is a separate follow-up development project.
- Stable releases are created manually from `master`; development releases remain available separately.

Use **Settings → CHECK FOR UPDATES** after publishing v1.1.8, or install the official Windows x64 Inno Setup package. Unsigned builds can trigger Windows SmartScreen prompts.
